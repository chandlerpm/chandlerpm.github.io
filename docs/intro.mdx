Eleven samples, grouped in the sidebar by documentation type rather than by where they came from: reference and procedural guides, onboarding material, developer and support docs, a feature spec, information architecture, and instructional design.

Provenance varies by sample, and each one states it up front. Two — the Vectorworks Technical Guide and Project Sharing Concepts — are de-identified work from Frank Shirley Architects: firm name, server addresses, and client references are replaced with placeholders, but the procedures and structure are otherwise unchanged from what the team used. Three — the API setup guide, a knowledge-base article, and a set of release notes — are freelance client work from 2013–2017, recreated rather than pulled from client files. Five are self-directed: an SOP library, an onboarding guide, a knowledge-base architecture framework, a documentation-tooling system, and a feature spec for a personal SaaS project, each written to demonstrate systems thinking as much as writing. The HTML/CSS curriculum is original course material.
